# Repository tools

These commands support dataset maintenance, annotation, validation, and research.
They are not runtime entrypoints. Run a tool from the repository root and review
its arguments before allowing it to write artifacts.

- `dataset/`: corpus and benchmark maintenance.
- `annotation/`: annotation sampling and reporting.
- `validation/`: cross-artifact validation and diagnostics.
- `research/`: experiment-specific analysis, including frozen Phase 5 tooling.
- `legacy/`: historical utilities that target obsolete layouts or schemas.
